# 复扫雷 Complexweeper（Web 版）

> [English README](README.en.md)

扫雷，但雷是复数：支持复数与双曲复数两种模式，格子上的数字是周围所有雷之和的模长（双曲模式使用形式模长）。

翻开所有非雷格子就胜利。
结局会用勾和叉显示标对、标错的雷，并播放对应音效。

**纯静态 Web 应用**：Vite + TypeScript + Canvas 2D，无运行时依赖、无后端，构建产物可直接托管到任意静态平台，支持 PWA 离线游玩。

**在线试玩**：https://miofelix.github.io/complexweeper-web/

## 规则

**复数模式**有四种雷：正实雷、负实雷、正虚雷和负虚雷，也就是 +1、−1、+i 和 −i。

一个格子显示的数是周围所有雷之和的模长。

因为周围最多 8 格，所以只可能出现 24 种数字：

0, 1, 2, 3, 4, 5, 6, 7, 8,
√2, √5, √10, √13, √17, √26, √29, √34, √37,
2√2, 2√5, 3√2, 4√2, 5√2, 2√10。

正负雷数量相等时会互相抵消，这种 1 正 1 负的正负对我们称为"抵消对"；
0 和空白不是一回事。空白格子表示周围完全没有雷；0 表示周围完全为抵消对。

当数字格子周围插上的旗帜数量等于真实雷数，且实虚比例符合真实比例或其倒数，则允许展开；可以利用这一点试探周围是否有抵消对。
谨记扫雷的胜利判定是翻开所有的格子，而不是插对全部的旗帜。

**双曲复数模式**使用 +1、−1、+j、−j，其中 j² = 1。邻域和为 a + bj 时，显示 √(a² − b²)；负值显示为带 i 的根式，例如 a = 0、b = 2 显示 2i。

此模式共有 39 个显示值。展开要求旗帜总数等于真实雷数，且旗帜净和的实部与 j 部绝对值分别等于真雷净和；可分别变号，不能交换实部与 j 部。双曲模式的 0 也可能来自非空的零因子组合，例如 1 + j，不会当作空白连片展开。

工具条的两个模式菜单各含三档难度、自定义和该模式的纪录；选择难度或应用自定义会开启新局，查看纪录不会切换当前对局。

## 操作

| 操作 | 鼠标 | 触屏 |
| --- | --- | --- |
| 翻开格子 | 左键 | 点按 |
| 插旗（正实 → 负实 → 正虚 → 负虚 → 撤旗） | 右键 | 长按，或开启「插旗模式」后点按 |
| 展开格子 | 中键，或左右键同时点击 | 双击已翻开的格子 |
| 重开 | 点人脸按钮 | 同左 |
| 开局 | F2 | 「开局」按钮 |

开启插旗模式后，鼠标左键也会循环插旗。使用触控笔时，笔尖翻开、侧键插旗。大棋盘可横向滚动；触屏上拖动浏览时不会翻开格子。

第三、四种旗帜的单位随模式变为 i 或 j。音效包含四种踩雷音、通关音和每秒计时音，可用工具条「音效」按钮关闭。

## 难度

- 初级 9×9 · 10 雷
- 中级 16×16 · 40 雷
- 高级 30×16 · 99 雷
- 自定义：宽 9–40、高 9–30，可只定总雷数（类型随机撒），也可指定四种雷各自的精确配比

自定义弹窗的“雷类型”可切换随机分配与指定配比；切换时保留两种模式各自的输入。

两个模式各有独立的三档最快通关纪录，保存在浏览器 `localStorage`；升级保留原复数模式纪录，自定义棋盘不计入。

## 本地开发

```bash
npm install      # 需要 Node.js ≥ 20
npm run dev      # 开发服务器（默认 http://localhost:5173）
```

## 构建与测试

```bash
npm run test       # 规则引擎与布局单测（vitest，对照桌面版自检点）
npm run typecheck  # TypeScript 严格检查
npm run build      # 静态产物输出到 dist/
npm run preview    # 本地预览构建产物
```

`dist/` 是纯静态文件，可部署到 GitHub Pages / Vercel / 任意静态托管。

## 项目结构

```
public/assets/   图像素材（图集 PNG + 槽位表 JSON、图标）及 sounds/ 音效
src/game/        规则引擎（纯 TypeScript，不依赖 DOM，可独立测试）
src/render/      Canvas 2D 渲染（图集加载、布局计算、绘制）
src/input/       鼠标 + 触屏输入 → 语义动作
src/app/         装配：计时、最高分纪录、对话框、工具条
tests/           vitest 单测
docs/           素材授权与上游同步说明
scripts/         图标生成等构建辅助脚本
```
